The web-based frontend for the Divum Minecraft server management platform. Provides a graphical interface for managing servers, users, and configuration.

## Tech Stack

- **Language:** TypeScript
- **Framework:** Angular
- **Topics:** angular, minecraft, minecraft-server

## Features

- Dashboard for monitoring server status
- Create, configure, and manage Minecraft servers
- User management interface
- Real-time server status updates
