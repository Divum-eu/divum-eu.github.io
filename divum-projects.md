This site documents the Divum open source projects — a platform for managing Minecraft servers.

## Services

The platform is composed of three main services:

- [divum-backend](/divum-backend) — The main API that handles users, server creation and configuration, and monitoring.
- [divum-daemon](/divum-daemon) — A stateless API for building, stopping and managing Minecraft server instances.
- [divum-web-client](/divum-web-client) — The web-based frontend for managing Minecraft servers through a browser interface.
