A stateless API that manages the lifecycle of individual Minecraft server instances on the host machine.

## Tech Stack

- **Language:** Python
- **Framework:** FastAPI
- **Containerisation:** Docker
- **Topics:** docker, fastapi, minecraft, minecraft-server

## Features

- Build Minecraft server containers from configuration
- Start and stop server instances
- Monitor server status and resource usage
- Works as the execution layer beneath the backend API
