The main API service for the Divum Minecraft server management platform.

## Tech Stack

- **Language:** Java
- **Framework:** Spring Boot
- **Topics:** minecraft, minecraft-server, spring-boot

## Features

- User management — create, edit, and authenticate users
- Minecraft server lifecycle — create, start, stop, restart, and remove servers
- Server configuration — update server properties, resource packs, whitelist, and operators
- World export — download server worlds
- Real-time status monitoring via WebSocket
- Token-based authentication
